- **BI Application** сначала запрашивает метаданные из **Metadata Repository** (расположенного внутри DWH), чтобы понять, какие данные доступны и как к ним обращаться.
- После получения метаданных, **BI Application** извлекает фактические данные из **Data Repository (DWH)** для формирования отчетов.
